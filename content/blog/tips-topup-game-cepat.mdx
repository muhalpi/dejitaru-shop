Topup game bergantung pada akurasi data akun.

## Data wajib yang harus akurat

1. User ID game.
2. Server ID jika game membutuhkannya.
3. Pilihan game dan nominal topup.

## Rekomendasi praktis

- Simpan data akun game kamu di catatan agar tidak salah ketik.
- Pilih nominal sesuai event atau kebutuhan push rank.
- Gunakan satu channel komunikasi agar order mudah ditelusuri.
